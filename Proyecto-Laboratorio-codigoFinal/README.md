# Administrador de tareas
Proyecto realizado en **JavaScript** y **Typescript** con *inquirer* y *colors*.
Tiene una base de datos realizada en **SQL**, usuarios. Se pueden agregar, completar y borrar tareas.

Para su ejecución es necesario ejecutar previamente lo siguiente:
- npm install
- npm install typescript --save-dev
- npm install --save-dev ts-node @types/node
- npm install --save-dev @types/colors @types/inquirer
- npm install --save-dev jest @types/jest ts-jest

Iniciar el proyecto: 
- npx ts-module src/app.js
- npm run dev
